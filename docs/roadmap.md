# 10-Day MVP Roadmap

| Day | Deliverable | Acceptance check |
|---|---|---|
| 1 | Environment, GPU verification, data/licence inventory | Reproducible environment and documented data source |
| 2 | Video inspection and frame extraction | CLI extracts frames with timestamps and metadata |
| 3 | Pretrained player detector baseline | Annotated sample video and detection metrics |
| 4 | Football-ball detection baseline / fine-tuning decision | Ball examples reviewed; limitations recorded |
| 5 | ByteTrack integration | Track IDs rendered on a short clip |
| 6 | BoT-SORT comparison and team clustering | ID-switch examples and team labels inspected |
| 7 | Ball association, possession, heatmaps | Analytics generated from saved tracks |
| 8 | Homography prototype and pitch visualization | Calibration assumptions and failure cases documented |
| 9 | Evaluation report, API skeleton, dashboard prototype | Repeatable evaluation and one end-to-end demo |
| 10 | Cleanup, tests, Docker, README, demo | Fresh setup instructions verified |

The order may change based on dataset availability and ball-detection quality. A reliable, measured subset is preferable to a broad but unverified feature list.
